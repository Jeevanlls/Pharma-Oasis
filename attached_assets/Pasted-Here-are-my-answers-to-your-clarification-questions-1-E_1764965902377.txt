3️⃣ Categories & Subcategories
Use one categories table with parent/child relationships – no separate subcategories table.
categories:
id
name
parent_id (nullable – NULL = top-level category)
Mapping logic for CSV:
category_name → parent category (parent_id = NULL)
subcategory_name (if present) → child record whose parent_id = parent category id
In products:
Store both:
category_id (top-level)
subcategory_id (nullable, child)
If subcategory_name is empty, just use category_id.

message

5️⃣ Quote Status Values
Let’s define a simple, clear status workflow:
Allowed statuses for quotes.status:
pending – created by customer, awaiting review (default)
quoted – admin has prepared/sent a quote
accepted – customer has accepted the quote (set manually by admin)
declined – quote declined / not proceeding
closed – completed/archived (final state)
Default on creation: pending.
Admin UI should allow changing between these values.
