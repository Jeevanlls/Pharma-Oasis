3. FUNCTIONAL & DESIGN REQUIREMENTS (FROM WORD DOC)
Use the Word file as the full details, but here is a short reminder so you don’t forget key points:
Single Replit project – frontend + backend + DB + admin.
Stack: React + TypeScript + Tailwind; Node/Express or Next.js API; Prisma + SQLite (or equivalent).
Roles: Visitor, Customer (approved), Supplier lead, Admin.
Features:
Public marketing site + product catalogue (no prices for visitors).
Customer registration & admin approval flow.
Login for approved customers only.
Quote basket + quote request flow.
Supplier registration lead form (no login).
Admin panel: customers, suppliers, products, brands, categories, quotes, site settings.
CSV bulk import for 4,000+ products with mapping from brand_name/category_name.
All content dynamic / database-driven (homepage texts, static pages, etc.).
Theming system with three switchable themes defined exactly as in the spec.
Every time there is a clash between your own idea and the document, the document wins.
